## 🚀 Featured Projects

### [AETHER](https://github.com/Mr-strom/AETHER) — Offline Multimodal RAG Engine
Privacy-preserving, CPU-first document analysis system.  
**Stack:** Python · FAISS · BGE-M3 · GGUF (Granite/Qwen) · FastAPI · React  
**What it does:** Ingests PDFs, DOCX, CSVs → chunks → embeds → retrieves → synthesizes grounded answers with citations. Fully offline.

### [JEEVA_SETU](https://github.com/Mr-strom/JEEVA_SETU) — Healthcare Access Platform
Monorepo healthcare platform built for real-world deployment.  
**Stack:** TypeScript · React · Node.js · PostgreSQL · Docker Compose  
**What it does:** Patient-provider bridge with safety-gated workflows, audit trails, and pilot-ready infrastructure.

### [CAREER_OS](https://github.com/Mr-strom/CAREER_OS) — Career Intelligence Desktop App
A Tauri-powered desktop + web career tracking system.  
**Stack:** Tauri · React · tRPC · Drizzle ORM · Tailwind · Radix UI  
**What it does:** Local-first career OS with offline sync, analytics, and AI-assisted resume insights.

### [AEGIS](https://github.com/Mr-strom/AEGIS) — IT/OT Security Console
Neomorphic cybersecurity dashboard with live telemetry visualization.  
**Stack:** Vite · Vanilla JS · SVG Canvas · CSS Grid  
**What it does:** MITRE ATT&CK chain graphing, SHAP explainability UI, and human-gated response gates.
